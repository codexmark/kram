Kram v0.2.6 restores the supplied KRAM identity mark and turns it into a
responsive terminal boot splash.

- replaces the unrelated `KramGateway` FIGlet banner with the exact
  retracting-legs K, ANSI Shadow KRAM wordmark, motto, border, background,
  alignment, and violet-to-cyan gradient from the supplied reference;
- reveals the mark from left to right, holds briefly, then fades and dissolves
  before starting the first-run wizard, session picker, or selected chat;
- keeps the entire transition inside one Bubble Tea program, avoiding an
  alternate-screen flash between the splash and its destination;
- allows Enter, Space, or Escape to skip the animation without forwarding the
  key to the next screen;
- adapts safely to medium and narrow terminals without wrapping or corrupting
  the full composition;
- locks the source cells, alignment, colors, animation geometry, and startup
  transitions with regression tests.

The full local gate passed: formatting, `go vet`, all packages with the race
detector, host build, Windows cross-build, Android/Termux cross-build, and
installer behavior/static checks.

Issues #9 and #10 remain open because their implementations still require the
clean Windows amd64 and physical Android/Termux acceptance runs specified in
their checklists. This release does not treat cross-build success as evidence
of runtime acceptance on those platforms.
