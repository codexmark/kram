# Kram Public Beta

Kram is currently in **Public Beta**.

The runtime is already usable for real coding work and is distributed for Linux, macOS, Windows amd64, and Android/Termux arm64, but the project is still actively stabilizing behavior across different repositories, terminals, shells, providers, and operating systems.

## What feedback is most useful

Please report:

- installation or startup failures;
- onboarding friction;
- provider or model compatibility problems;
- incorrect tool, permission, session, routing, memory, MCP, or LSP behavior;
- platform-specific problems;
- reproducible crashes, hangs, process leaks, or state inconsistencies;
- places where Kram's behavior is unclear or misleading.

Use the repository issue templates so reports include the environment details needed to reproduce the problem.

## Reporting safely

Never post API keys, OAuth tokens, credentials, private repository contents, or other secrets. Sanitize logs, screenshots, paths, and command output when necessary before sharing them publicly.

## Current support boundaries

The main README documents the current runtime boundaries and installation paths. Public Beta does not mean every agent-runtime problem is considered solved; it means the existing system is ready to be exercised by users outside its original development environment so those remaining problems can be found and corrected with real evidence.
